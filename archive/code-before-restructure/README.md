# Исходный код до реорганизации

Здесь сохранены точные версии скриптов, использованных до изменения структуры проекта. Их SHA256 совпадают с fingerprints в исторических результатах. Эти файлы служат источниками воспроизводимости; рабочие команды находятся в пакете `read_prediction`.

Проверки исторических результатов сверяют записанный hash с этими снимками. Новые эксперименты записывают fingerprints текущего пакета. Модели, baseline, прогнозы и исходные записи результатов не заменяются новыми численными значениями при реорганизации.
