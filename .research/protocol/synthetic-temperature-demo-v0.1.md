## 2. Полностью заданный предлагаемый генератор SYN001
- SYN001 — proposed dataset/config ID, НЕ существующий источник/артефакт. Одна namespace `synthetic0`, 96 logical pages p=0..95, offset=4096*p bytes; recording [0,21600) секунд, endpoint=21600 по определению генератора, без запроса на endpoint.
- 36 bins j=0..35, bin=[600*j,600*(j+1)); два обязательных заранее объявленных случая, без выбора успешного: `phase_cycle` и `independent_negative`.
- Cycle: states=(0,1,2), counts=(0,1,4), c[p,j]=counts[states[(p%3+j)%3]]. Это намеренно engineered signal, не модель реального workload.
- Negative: отдельный Python stdlib `random.Random(42)`; ровно один `randrange(3)` для каждого (j,p), j ascending, затем p ascending; c[p,j]=(0,1,4)[draw]. RNG не используется для другого; seed не подбирается, точный Python version фиксируется до выполнения.
- c=0: READ нет; c=1: READ at 600*j+300; c=4: READ at 600*j+{60,180,360,480}. Каждый READ имеет offset=4096*p,size=4096; timestamp — ordinary issuance seconds, не искусственный порядок страниц.
- Для обоих случаев: в s+1 seconds, s∈{0,12000,16800} (0/200/280 min), по одному WRITE size=4096 на ВСЕ 96 pages. Это causal registration, сохраняющая cold pages; не свидетельство physical mapping/доступности SSD.
- Сначала создать все 6h, включая оба gap, затем mask. Порядок сериализации (timestamp, WRITE-before-READ, offset_bytes); request_id=case+ordinal с ordinal от 0, уникальный в case; ties обрабатываются batch, row order не даёт predictor знания.
- Raw CSV schema: `request_id,timestamp,namespace,op,offset_bytes,size_bytes`; op строго READ/WRITE, integer seconds/bytes. Нет скрытой multi-page sequence: один generated request — одна page; отдельные fixtures проверяют overlap.
- Design bound: ≤14112 events/case (96*36*4+288 WRITEs), ≤28224 всего; fixtures≤100 events, общий hard cap30000. Фактические counts UNKNOWN до run; не выдавать bound за измерение.
- Независимый label counter читает READ trace и НЕ recipe/c[p,j]; predictor никогда не получает recipe/expected labels. Сравнить counts каждого page/bin с независимой таблицей ожиданий recipe; она — expectation, не observation.

## 3. Окна, universe, признаки и masks
- Сохраняем conventions: logical4KiB, history/H/step=600s; labels: cold0, warm1–2, hot≥3 future READ requests. Для request(o,size>0) pages=floor(o/4096)..floor((o+size−1)/4096); +1 на overlapping page на исходный READ, не на байт.
- U(t): pages из R/W с issue<t после reset сегмента. Features из [t−600,t), labels из [t,t+600); события в t только future, ties целиком исключены из past. Writes только регистрируют/дают write-count, не READ labels.
- Fixed minutes: train[0,180), gap[180,200), val[200,260), gap[260,280), test[280,360). Reset U/history в начале каждого train/val/test; gap events не используются, weights tree после train frozen, no online fit.
- Warmup10min; grid start+10..end−10 inclusive, step10min: 17/5/7 decisions. Благодаря registration предлагаемая полная U=96 при каждом решении: train1632/val480/test672 examples/case (design arithmetic, НЕ результат); без sampling/pooling/class filtering.
- Ключ `(case,split,namespace,page,decision_seconds)` общий Z,D,A,X. Неполное history/future, gap/end/reset пересечение — censored с reason, не cold; selected окна должны быть полными. Expected censored/grid checks фиксируются до labels.
- X feature order: readcount600, readcount300, recency=min(t−last_past_read,600) seconds (нет read→600), writecount600. count600≥count300. Recency использует только последнее past READ данного сегмента.
- Запрещены model features: page/ID/address/namespace, generator phase/bin ID, absolute time, seed, future/expected-count columns. IDs/time используются только для causal counting/join/mask. Ни global vocabulary, ни train/test future overlap.
- Unseen p∉U(t): default=cold; не добавлять future readers в eligibility. Отдельно per-decision future unseen pages/classes/errors и seen-read incidence coverage=seen incidences/all future READ page-incidences (0 denominator→NA); primary metrics только полная U(t).

## 5. Сравнения: одна фиксированная offline implementation
- Z=past-frequency по r600: 0/1–2/≥3 → cold/warm/hot. D=always-cold. X=fixed small tree по четырём features; A=count-only tree по r600, retained ablation. Masks/labels/eval keys строго одинаковы, unseen default общий.
- Proposed route: один single-process/single-thread Python stdlib custom greedy CART; НЕ sklearn replication и НЕ NN. Это новое implementation-предложение вместо прежнего sklearn; exact runtime/algorithm code надо инспектировать до исполнения, никаких installs/автоfallback.
- CART: root depth0, max_depth3, min_samples_leaf50, unweighted Gini=1−Σ(nclass/n)², all features at each node; сортировать distinct train values, кандидаты midpoint каждой adjacent пары, split left≤threshold/right>threshold; оба leaf sizes≥50.
- Выбрать максимальный parent Gini−weighted child Gini, считать/сравнивать точно (`fractions.Fraction`, midpoint тоже exact). Tie: feature order из §3, затем smallest threshold. Pure node/depth3/no valid split/gain≤0 → leaf; predicted class=max count, ties cold<warm<hot; no pruning/class weights/normalization/random split.
- Только train данного case, стабильный row order (decision,page). 2 cases*2 trees=4 fixed fits, zero tuning; models independent across cases. Seed42 fixed для recipe/config, CART deterministic, никаких дополнительных seeds/поиска/early stopping по F1.
- Evaluation order cases cycle→negative, methods Z,D,A,X, val→test по одному release, weights неизменны; val — sanity report, не выбор. Качество val не разрешает менять test/модель; causal/implementation defect останавливает comparison как invalid, не «плохое качество».
