# Манифест артефактов

`manifest.json` фиксирует относительные пути, размеры и SHA256 моделей, метаданных, трасс и массивов прогнозов. Раздел `selected_models` указывает две итоговые модели и их frozen-описания.

- `storage: git` — модели и JSON-метаданные, которые входят в репозиторий.
- `storage: external` — файлы, которые хранятся отдельно и исключены из Git.

Манифест содержит сведения о файлах, а не сами внешние данные. Подробности переноса и восстановления: `../docs/git-storage.md`.

```bash
# Проверить сохранённый в Git комплект
uv run python -m read_prediction.artifacts verify

# Проверить также локальные трассы и прогнозы
uv run python -m read_prediction.artifacts verify --include-external

# После нового эксперимента обновить список и контрольные хеши
uv run python -m read_prediction.artifacts record
```

Команды запускаются из корня проекта. Обновление манифеста читает большие файлы целиком, но не загружает их целиком в память.
