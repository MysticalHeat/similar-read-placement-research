# Все Write: причинные признаки серий I/O

Дни 5–7 уже просмотрены: новый эксперимент диагностический. Source — тот же полный префикс до 168h/EOF, event-cap 200 млн означает STOP. Все Write начиная с 96h включаются в выборку. Next Read и next Write ищутся по точному начальному Offset, не пересечениям диапазонов; порядок строк разрешает равные timestamps.

Исход к границе окна: Read-first, Write-first или неизвестный (первое событие ещё не наблюдалось). Неизвестные не становятся отрицательным классом. Обучение binary gate использует только исходы, разрешившиеся до границы обучения, но метрики включают все Write. Условный прогноз обучается на Read-first, разрешившихся до этой границы. Цензурированные случаи остаются в знаменателях conservative precision и подтверждённых error<overwrite.

Признаки только из прошлого до текущего Write: прежние 7 causal-признаков, число Write после последнего Read (без текущего), размер предыдущей Write того же адреса, количества Read/Write в последней полностью завершённой секунде и последних 60 завершённых секундах от начала трассы, sin/cos времени суток, расстояние адреса и интервал после предыдущей Write всего volume. Статистика не зависит от будущего Read или попадания Write в наблюдаемую выборку. Текущие Offset/size допустимы. Отдельная forward/backward reference-проверка восстанавливает признаки и next events для 64 Write каждой нагрузки.

Для ограниченной памяти source разбивается на 128 buckets по адресу; сортируются только buckets, признаки/meta записываются в memmap. Источник не удерживается как Python objects. Глобальная хронология и исходные индексы сохраняются.

Day 5 train, day 6 validation/выбор, day 7 повторная диагностика. Два classifier-рецепта, 31/63 leaves, максимум 96 деревьев; два conditional-time рецепта raw-L1/log-L1, 31 leaves, максимум 96 деревьев. learning_rate=.1, min_child_samples=200, reg_lambda=1, seed=42, deterministic, два потока. Early stopping 12 итераций: logloss для gate, MAE секунд для time на известных Read-first. Training classifier максимум 2 млн известных исходов, regressor максимум 1 млн Read-first, early-stop validation максимум 1 млн; равномерная выборка без возвращения RNG42, индексы сортируются. Итоговые validation-метрики считаются на всех Write дня 6.

Baseline времени — current, восстановленный из старой модели по тем же первым семи признакам. На старом наблюдаемом наборе используются точные сохранённые прогнозы, чтобы сравнение оставалось идентичным. Probability thresholds .5/.6/.7/.8/.9/.95/.99. Требование выборочного режима: lower precision Read-first >=90%, lower доля подтверждённых error<overwrite среди ВСЕХ selected >=90%, coverage ВСЕХ Write >=10%. Из проходящих максимальное coverage, затем MAE наблюдаемых selected. Если проходящих нет — выбирать лучший минимум двух нижних долей среди coverage >=10%, а если нет и таких — maximum coverage. Empty selection не успех.

Выбор фиксируется до оценки дня 7; gate/time refit на известных исходах дней 5–6 с фиксированным числом деревьев и теми же caps. Порог после refit не меняется. Для исходного критерия все Read, завершившиеся до конца дневного окна, сравниваются без отбрасывания: routed использует selected time в selected группе и current вне её. 90% selected не означает общие 90%. Ненаблюдаемые Read не объявляются нулевыми ошибками.

Сохраняются source hash, features/meta, samples source audit, все validation-прогнозы/модели, выбор, refit-модели, hashes и независимые counts. events.bin остаётся внешним audit-кэшем. Старые frozen-артефакты не изменяются.
