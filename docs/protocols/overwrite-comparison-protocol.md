# Сравнение MAE со временем до перезаписи — 2026-10-06

Диагностическая проверка уже сохранённых прогнозов дней 5–7, без обучения и выбора новых моделей.

- Перезапись здесь означает следующую Write с тем же точным начальным Offset и logical volume. Это прокси на уровне адреса, не анализ пересечений диапазонов/блоков и не доказательство полной замены версии данных.
- Для каждого уже оценённого Write определяем следующую Write по порядку строк во всём исходном префиксе до EOF/168h. Допускаем перезапись за границей текущего дневного окна. Никаких других записей в исходную MAE не добавляем.
- Интервал — разность целых FILETIME / 10^7. При одинаковых timestamps используется порядок строк. Нулевые интервалы остаются в знаменателе строгого критерия error < overwrite; деление error/overwrite считается только для положительных интервалов.
- Отсутствие следующей Write — цензурирование, не бесконечность и не нулевой интервал. Публикуем количество таких записей. Наблюдаемый нижний предел — last_observed_timestamp − write_timestamp. Если error меньше него, критерий заведомо выполнен; в остальных случаях неизвестен. Нижняя граница общей доли — известные проходящие + заведомо проходящие цензурированные; верхняя — известные проходящие + все цензурированные.
- На совпадающей выборке с известной перезаписью публикуем MAE, среднее/медиану/P10/P90 интервала, долю error < overwrite, медиану/P90 отношения error/overwrite. Отдельно показываем MAE на всей исходной выборке; различие выборок не скрываем.
- Для всех оценённых записей проверяем Read index < next Write index (или следующая Write отсутствует после наблюдённого Read). Публикуем долю чтений раньше повторной записи. Отдельно сравниваем ошибки и перезаписи для этой группы.
- Методические варианты публикуются все: current, address_median, selected. В кратком выводе используются ранее рекомендованные selected для usr_1 и current для prxy_1; это не новая настройка по этим метрикам.
- Среднее/медиана перезаписи — разные диагностические ориентиры. MAE < mean overwrite сама по себе не гарантирует правильную группировку. Ширина групп/прикладной критерий группировки не заданы, поэтому фактическую точность группировки не заявляем.

Исходный префикс, rows, predictions и frozen models проверяются по SHA256 прежнего эксперимента. Следующая Write рассчитывается стабильной группировкой только Write событий; для максимум 64 примеров каждого дня независимо проверяется первым последующим Write в прямом хронологическом проходе. Метрики независимо пересчитываются из новых аннотаций и прежних прогнозов. Артефакты — results/overwrite-comparison/, отчёт — reports/overwrite-comparison.ru.md. Кэш событий удаляется после успешного расчёта. Переобучений: 0.
