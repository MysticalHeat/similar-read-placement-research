# Порог 90%: ограниченный диагностический эксперимент

Порог фиксируется до расчёта новых кандидатов: нижняя граница доли `abs(prediction - next_read_delay) < next_write_delay` должна быть не менее 0.90. Все прежние завершённые примеры входят в знаменатель, включая нулевые интервалы; отказов от прогноза нет. Следующая Write определяется по точному начальному Offset, не по физическому перекрытию диапазонов. MAE публикуется как дополнительная метрика.

Дни 5–7 уже просмотрены: это повторная диагностика, не новый независимый holdout. История завершённых примеров дней 2–4 прогревает причинные признаки; день 5 обучает четыре кандидата, день 6 выбирает рецепт и best_iteration по нижней границе доли проходящих. Выбор сохраняется до оценки дня 7. Выбранная модель переобучается на днях 5–6 с фиксированным числом деревьев; простые рецепты не подгоняются дополнительно. День 7 сравнивает замороженный рецепт с прежними прогнозами на одинаковых записях.

История содержит только пары Write/Read, чей Read строго предшествовал текущему Write по исходному порядку строк. Используется доступная сохранённая история завершённых внутри дневных окон примеров, не вся история трассы; переходящие через полночь пары не добавляются. Ни текущая метка, ни будущая перезапись не являются признаками. Признаки: log1p прежнего прогноза и адресной медианы, последней завершённой задержки, медианы/среднего последних пяти задержек, времени после последнего завершённого Read и числа завершённых пар; sin/cos времени суток и log1p Offset.

Простые рецепты: current, address_median, last_completed, median5, mean5, смесь current/median5 с весами current 0.25/0.5/0.75, масштабы current 0.5/0.75/1.25. Без истории используется current. Модельные рецепты: raw-L1 и log-L1 × равномерные/ограниченные обратные веса времени до перезаписи. Веса `clip(1/max(budget,1),0.01,1)`; наблюдённые нулевые интервалы получают нулевой обучающий вес, но остаются в метрике. Для весов доступны только Write до момента обучения; для не наблюдённых к этому моменту перезаписей budget — прошедшее время до границы окна. При финальном fit на днях 5–6 это граница 144h, не EOF/будущие события дня 7.

LightGBM: максимум 64 дерева, 15 leaves, min_child_samples=200, learning_rate=0.1, reg_lambda=1, два потока, seed=42, deterministic. Early stopping после 12 итераций без улучшения консервативной доли проходящих на дне 6. Для validation следующая Write после 144h считается неизвестной, даже если она присутствует в сохранённой будущей трассе. Tie-break: меньшая MAE, затем имя рецепта. Для финальной диагностики используются прежние интервалы перезаписи до EOF и прежние цензурирующие пределы.

Сохраняются входные/code hashes, выбор, все validation-метрики, модель при наличии, прогнозы дня 7, дневные границы и независимая проверка. Отдельный checker восстанавливает историю для выборочных прогнозов прямым просмотром предыдущих завершённых пар и пересчитывает числа проходящих из исходных прогнозов/аннотаций. Старые frozen-артефакты не изменяются. Достижение 90% не обещается; повторная диагностика не доказывает перенос на новые данные.
