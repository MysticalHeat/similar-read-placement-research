# Независимый будущий период prxy_1: вторые сутки

До выполнения фиксируем период `[t0+24h, t0+48h)`, где t0 — первое событие prxy_1. Первый день уже использован для обучения, выбора и просмотра прежнего test; его test не служит новой независимой проверкой выбранной модели.

- Единственный основной кандидат — уже сохранённый `no_counts_log_l2`; никаких новых fits, early stopping, настройки признаков или выбора лучших часов.
- Модель обучена на первых 60% первых суток. Baseline-медианы восстанавливаются **только по тем же завершённым обучающим интервалам**, замораживаются и не обновляются в течение вторых суток. Для неизвестных адресов — прежняя общая медиана.
- Сравнить общую медиану, медиану адреса, исходную модель и выбранную модель. Основная метрика — MAE секунд, дополнительные прежние четыре метрики. Все 24 часовых результата публикуются как описательная диагностика, не используются для выбора часов/модели.
- История признаков обновляется из наблюдаемых событий в том числе между обучением и новым периодом. Начальный Offset и правило первого следующего чтения прежние. Цензурированные записи до конца вторых суток исключены из оценки и учтены отдельно.
- Потоково загрузить 48 часов, cap 70 млн событий; если конец временного окна не достигнут, STOP, без замены периода. Временные кэши дисковые, два потока inference. Hash модели и manifest выбора сохраняются **до расчёта новых labels**, проверяются после выполнения.
- Сохранить все прогнозы, метрики, coverage, замороженные baseline, source/code/model hashes и измеренные время/RSS. Отдельно пересчитать метрики и выборочно сверить новый период с исходными строками. Проверка характеризует один последующий день того же volume, не независимую популяцию нагрузок и не SSD speedup.
