# Дополнительная диагностика: исход до заданной границы окна

Мотив: binary gate all-write обучается на разрешённых исходах и не моделирует вероятность того, что событие успеет наступить. Этот дополнительный протокол фиксируется после диагностики usr_1, до новых fits. Все дни уже просмотрены: нового holdout нет.

Переиспользуем неизменённые source/17 причинных признаков/meta из results/all-write. Новый classifier предсказывает три исхода **до конца заранее заданного 24h-окна рождения Write**: Write-first (0), Read-first (1), ни одного первого события до границы (2). Последний класс не означает «никогда не прочитают» или физический Write-first. Обучающие дни 5–6 полностью наблюдены до своих границ; если source заканчивается раньше 144h, STOP. На частичном дне 7 отсутствие события остаётся цензурированным для оценки, а не автоматически считается истинным классом 2.

Добавляется log1p оставшегося времени до плановой границы окна, доступного по текущему timestamp. Для дня 7 входная граница 168h, а не неизвестный в момент Write будущий EOF. Классы при refit дней 5–6 сохраняют границу собственного окна: события предыдущего дня, наступившие только на следующем, не становятся классом 1 задним числом.

Два multiclass LightGBM-рецепта 31/63 leaves, 96 деревьев максимум, learning_rate=.1, min_child_samples=200, reg_lambda=1, seed42, deterministic, два потока. Train cap 2 млн всех Write с RNG42, early-stop validation cap 1 млн, 12 итераций по multi_logloss. Threshold probabilities Read-first .5/.6/.7/.8/.9/.95/.99. Время — прежние validation-прогнозы current/raw-L1/log-L1 из all-write; никаких новых вариантов времени по дню 7. Выбор по прежнему all-write правилу: обе нижние доли >=90% при coverage всех Write >=10%, максимум coverage; fallback только среди coverage>=10% при наличии таких кандидатов.

Выбор записывается до дня 7. Refit gate на днях 5–6 с фиксированным best_iteration; условный time при необходимости refit на Read-first до собственного дневного deadline, с прежними params/best_iteration и cap1млн. Исходный error<overwrite на всех прежних наблюдённых Read сравнивается отдельно, без исключений. Все неопределённые и ненаблюдённые selected остаются в знаменателе подтверждённой доли проходящих. Сохраняются модели, inputs/code hashes, validation-прогнозы и независимая проверка counts/deadline/model replay.
